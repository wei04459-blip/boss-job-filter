## 本轮发现并修复

1. 导出路径固定在单台 Mac 的缓存目录：改为读取实际运行库路径，缺少时提供不依赖 Node 的后端。
2. 依赖默认已安装：增加根安装器、技能内 bootstrap 和跨平台启动器。
3. 初次连接更换后，上游延迟加载的 websocket 未初始化：隔离真实运行暴露了该错误；补初始化与回归检查后成功完成真实采集。
4. 原验证器不能读取空的 inlineStr 单元格：修复后两种后端均通过保存文件检查。
5. 未知城市可能触发上游内部接口兜底：改为只查随附城市表，未知时明确报错。
6. 异常退出后可能留在 running 状态：增加异常保存，避免将失败结果误读为仍在采集。
